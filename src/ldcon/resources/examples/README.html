Example configurations

Sr422 (ECDL), Sr1092 (DFB/DBR) and ThF685 (DLCpro) configurations demonstrate devices, interfaces, decks and per-laser assignments. Export them with ldcon-examples ./my-lab.

These are illustrative snapshots, not commissioned configurations for another instrument. All laser allow_output flags are false. Addresses use documentation-only 192.0.2.0/24; USB serial numbers and local evidence references are placeholders. Do not enable output until the physical instrument, safety limits and commissioning evidence have been checked locally.

No credentials, live jobs, approval receipts or measurement histories are included. Configure authentication in a private local configuration or environment using the relevant service's documented mechanism. Parameter values describe these example lasers; they are not universal device limits.
