ECDL意図的ホップ・復旧試験

test.ecdl_recovery は、PI無効の状態でPZTまたは電流を明示した有限幅だけ変え、ホップが起きたかを確認し、作成済みの復旧経路を実行する試験カードです。通常の定常ロック中へ勝手に割り込むカードではありません。

事前条件

plan_ref には同じレーザーの成功した復旧計画job IDとSHA256を指定します。出発点が計画の元出力・元周波数・枝ラベル・光学判定文脈に一致することを、新しい有効取得で確認してから摂動します。古い校正、許可区間から外れる経路、別の光学判定設定は拒否します。

項目意味
perturbationsaxis が current または piezo、offset_fraction が元出力からの変化量。各軸の現在の許可幅に対する割合です。未指定では開始しません。
max_perturbation_fraction各摂動に許す上限。これを満たしても装置の絶対・相対範囲、速度、刻み上限を超える指令は通りません。
dwell_s / sample_interval_s移動後の待ち時間と確認取得間隔。実測の急な変化と新規確認標本を区別して記録します。
measurement_timeout_s / timeout_s一時的欠測を待つ期限と試験全体の期限。無期限に続行しません。

何を成功とするか

単に周波数が少し動いただけではホップ実証にしません。経路中の不連続または枝ラベル変化と、複数の新しい取得で持続する変化を確認します。その後、元の方向付き経路を再現し、元出力と周波数・パターン条件を再確認します。

結果は recovery-test.json。指定した全試行でホップと復旧が確認できれば succeeded、ホップが起きず戻せただけなら inconclusive（未判定）です。未判定は成功条件付き予約を通しません。試験終了時もPIは無効で、検証済みの出力を保持します。

不確実な書込み・書込後の検証失敗では、追加の復旧書込みや再試行をせず、ownerのfault・lease保持へ引き継ぎます。光学的文脈の再現は確認しても、物理的な縦モード番号や外部共振器／チップ由来を独立に同定したとは報告しません。
