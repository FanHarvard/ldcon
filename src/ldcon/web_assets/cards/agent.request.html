agent.request

Request gateway agent

Send a request to the running Gateway agent selected for this laser. It receives the instruction, delegates supported card tasks and returns their results. It is separate from the monitoring and adjustment cards.

Open the laser workspace, start Gateway agent if it is stopped, then use the request card or Open gateway conversation. Select the configured gateway card and enter your request. Reconnection resumes the saved conversation for the selected provider.

The gateway interface selects the task provider by default; the task card and difficulty routing select its model and effort. An explicit allowed execution profile can override that choice. The task model writes the explanation.

The displayed role is Gateway agent. The stored card ID is a routing key, not a display name. Use the ID from your laser deck when calling the API; do not rename an active card or a saved conversation to change its label.

Submitting a request is not proof that a physical action completed. Check its status, task results and owner receipts. Unknown delivery is not automatically replayed. Requests do not grant wider physical safety bounds; exact human approval is still required for those changes.

ゲートウェイへの依頼

このレーザーで稼働中のゲートウェイエージェントへ依頼します。ゲートウェイは依頼を受け、対応するタスクカードへ渡し、結果を返します。監視・調整カードとは別の役割です。

レーザー画面でゲートウェイが停止中なら起動し、依頼カードまたは会話を開くリンクから指示します。対象のゲートウェイカードを選択してください。再接続時は選択したプロバイダーの保存済み会話を継続します。

既定ではゲートウェイと同じインターフェースを使い、モデルとEffortはタスクカードと難易度の設定で選びます。許可された実行プロファイルを明示指定することもできます。説明はタスク担当モデルが作成します。

画面には役割名を表示します。保存されたカードIDは配送用のキーです。APIではレーザーのデッキに設定されたIDを使い、表示名を変えるために稼働中のカードや会話を改名しないでください。

受付成功だけでは実機操作の完了を意味しません。依頼状態・タスク結果・ownerの確認記録を参照してください。到達が不明な依頼は自動再送しません。安全範囲の拡大には具体的な差分に対する人間の承認が必要です。

向网关代理发送请求

向当前激光的网关代理发送请求。网关接收指令，委派支持的任务卡并返回结果；监控和调整由独立卡执行。

在激光工作区启动已停止的网关，然后使用请求卡或打开网关会话的链接。请选择已配置的网关卡。重连会继续所选提供商的已保存会话。

默认使用网关的接口，模型和推理强度由任务卡与难度配置选择。也可显式选择允许的执行配置。最终说明由任务模型编写。

界面显示角色名称。保存的卡ID是路由键。调用API时使用激光牌组中配置的ID；不要为了改变显示名称而重命名运行中的卡或会话。

请求被接受不代表实际操作完成。请检查请求状态、任务结果和owner确认记录。投递结果不明时不会自动重发。扩大物理安全范围仍需用户批准具体差异。
