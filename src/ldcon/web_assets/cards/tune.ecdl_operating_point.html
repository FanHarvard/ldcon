TEC branch alignment

tune.ecdl_operating_point approaches the requested frequency using calibrated TEC response and current feedforward, with PI off.

ParameterMeaning
recovery_artifact / recovery_refA same-laser v2 recovery artifact or hashed job reference. Its relative route and selection criteria are used; its archived return frequency is not an admission target.
tec_ffSigned frequency change per TEC input unit; defaults to the present temperature-axis calibration.
ldc_ffExplicit current-input change per TEC input unit. Calibration stays separate from recovery evidence.
approach_gainFraction of the measured frequency error to correct per iteration.
tec_settle_sWait after the bounded TEC/current move before measuring again.
max_tec_excursion_vRequested total TEC excursion from this run's start, additionally bounded by the owner.
pzt_trimOptional final bounded PZT trim. Its coefficient comes from the current piezo axis or an explicit value.

Each intentional step starts from a freshly measured stable checkpoint. The card compares the measured frequency change with the prediction. On a hop it restores its own recent TEC/PZT context, then executes the shared v2 current route. It never substitutes an old map's absolute branch reference. Only a completed route whose fresh return verification fails can retry within the configured finite budget; unknown writes and owner errors are not replayed.

Quality is recorded separately. Success requires the configured target tolerance and stable observation window. The card leaves PI disabled; lock start is a separate operation.
