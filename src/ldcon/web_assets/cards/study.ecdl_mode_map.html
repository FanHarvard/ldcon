ECDL大域マップと枝の候補選択

study.ecdl_mode_map は、目標光周波数を定め、PI無効・TECとPZT保持のまま、許可された電流範囲を一方向に走査する有限カードです。準備移動と本走査を区別し、各点の波長・周波数、単一モード判定、側峰・主峰幅、元のパターン、機器の校正・判定設定を記録します。

使う場面と終了状態

使う枝がまだ決まっていないとき、またはTEC/PZT・光学判定条件の変更後に現在の文脈を取り直すときに使います。上り・下りのいずれかを端点で指定し、本走査の途中では反転しません。走査終了点で出力を保持し、候補を選んだだけではその枝へ移動せず、PIも開始しません。

設定と成果

項目意味
target_frequency_hz目標光周波数。真空波長nmからは 299792458e9 / 波長nm で換算します。
current_start_fraction / current_end_fraction現在のownerが許可する電流区間の0〜1で走査端を指定。装置絶対限界や開始点からの相対限界を拡大する指定ではありません。
current_step_fraction / dwell_s同じ許可区間に対する刻みと各点で待つ時間。機器側の速度・刻み・整定下限も適用します。
conditioning_fractions本走査前の経路。空なら追加conditioningなし。準備移動とともに再現履歴へ残します。
discontinuity_hz / capture_hz観測経路を枝へ分ける不連続幅と、目標から候補を許す距離。装置・測定目的ごとの値を明示します。
ranking_weightsdistance / width / quality の重み。目標へ近い・観測した良好区間が広い・パターン品質が良い候補を順位付けします。
selected_branch_id / selection_author自動候補を採用するか、条件を満たす枝を人間・エージェントが選ぶかを記録します。

mode-map.json にSHA256付きのマップを保存します。連続した良好点から得た「観測窓幅」は、両側境界を実測した厳密な窓幅ではありません。境界と中心は定常ロック後の 窓・中心カードで確認します。

パターン指標の限界

固定した位相領域A/B/Cだけから普遍的な単一モード性を保証しません。自動候補には、周期の確認、全周期で位置を固定しない側峰・主峰幅の解析、装置設定で校正した判定が必要です。未校正のパターンは保存してレビュー対象にします。マップだけでホップの原因が外部共振器かチップかを断定せず、hop_cause: unknown を保持します。
