Native current operating point

Move a DFB/DBR laser to its requested wavelength while native PI remains off. The assigned device must already have a measured external-modulation response and a bounded PI profile.

Each DAC change is limited by the device current step, slew and activation envelope. The card waits for settling, averages new valid optical acquisitions and verifies stable arrival before succeeding. CLD bias, TEC and waveform-generator settings remain held.

The result records the response evidence, final DAC reference and target verification. The stationary lock rechecks fresh input before enabling PI; this finite card does not enable it.
