定常ロック中の電流マップ

study.ecdl_locked_current_map · version 1

開始できる条件

同一デッキの定常ロックと指定されたcontroller_card_idが動作中で、同じ所有者・リースに接続できること。

何を測り、何を動かすか

TECを保持して電流を両方向に走査し、受動ディザー応答と周辺モード強度を記録する。ディザーそのものの周波数・振幅をこのカードから再設定しない。

欠測・中止・安全条件

レーザー固有の絶対制限・速度上限・鮮度判定を常に優先する。一時欠測は既存の有限待機時間内で出力保持し、新しい有効測定で再計画する。不確実な書込み、安全限界違反、所有者faultは自動再送しない。停止要求は実行カードの出力停止・所有権解放を確認して完了とする。

必要なインターフェース

ecdl_stationary_lock

既定値と実行値

各レーザーの設定タブで、デッキ既定値とレーザー別上書きを合成した実行値を確認する。単位はパラメーター名と対応する機器設定に従う。実行時の値はログへ固定保存される。

実装根拠

Attach to the existing lock worker and owner lease. Hold TEC, sweep both current directions, retain raw fringe indicators and return to the initial bias while the lock remains valid.
